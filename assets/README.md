# README artwork

The Java mark and execution sketch support the repository index. All images are stored locally; the sketch has light, dark, and narrow-screen versions.

| File | Source and purpose |
| :--- | :--- |
| `logos/java.svg` | Java mark from [Devicon](https://github.com/devicons/devicon/blob/master/icons/java/java-original.svg), stored without modifications. Upstream blob: `051bf254ad782820627890ef2b0e06fbae63dc6e`. |
| `readme/java-execution*.svg` | Original execution sketch for this README: source → class files → JVM. It depicts the explicit compile-and-run path, rather than every Java launch mode. |

The execution sketch follows the JDK 25 command references for [javac](https://docs.oracle.com/en/java/javase/25/docs/specs/man/javac.html) and [java](https://docs.oracle.com/en/java/javase/25/docs/specs/man/java.html). It is a conceptual reference, not evidence of a recorded experiment.

Devicon's MIT notice is included in [logos/LICENSE-devicon.txt](logos/LICENSE-devicon.txt). Java and its mark belong to their respective owner; use here identifies the language.

The diagram SVGs use local shapes and text, with accessible titles and descriptions. They contain no scripts, embedded fonts, or external resources.
